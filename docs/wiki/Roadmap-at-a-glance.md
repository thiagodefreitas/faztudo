# Roadmap at a glance

The full plan is in the [roadmap](https://thiagodefreitas.github.io/faztudo/roadmap/).
This is the short version, as of the current main branch.

| milestone | what | state |
| :--- | :--- | :--- |
| M0 Foundation | license, rules, design docs, CI, docs site | done |
| M1 First dogfood | event log, API, chat, runs in worktrees, approvals, Claude and Codex | built |
| M1b Team chat and Lanes | threads, DMs, palette, four more adapters, Lanes dashboard, MCP server | mostly built; departments and the optional sandbox are open |
| M2 Usable alpha | LAN mode, search, pins, files, notifications, packages, security review, Chief of Staff and routines | LAN mode is built; the rest is open |
| M3 Signal | bridge through `signal-cli` | planned |
| M4 2D office | isometric office view of the same activity | planned |
| M5 Discord and extensions | Discord bridge, bridge protocol, adapters from a config file | planned |
| M6 3D office and desktop app | 3D view, Linux desktop app | planned |
| M7 Teams and federation | several people per workspace, more bridges | planned |

The repository becomes public at M2, after at least two weeks of building
faztudo inside faztudo.

Milestones and issues are tracked on GitHub. Pick an open issue in the
current milestone to help.
