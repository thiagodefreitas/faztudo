# faztudo wiki

Short pages for people who use or work on faztudo. The full reference is on
the [documentation site](https://thiagodefreitas.github.io/faztudo/) and in
`docs/` in the repository.

faztudo 0.1.0 is an alpha: you can install it from the
[releases page](https://github.com/thiagodefreitas/faztudo/releases). Pages
say "planned" when a feature is not built yet.

![A faztudo channel with run cards that open with a plain sentence](https://raw.githubusercontent.com/thiagodefreitas/faztudo/main/docs/images/chat.png)

See the office in motion: [20 second tour](https://thiagodefreitas.github.io/faztudo/#the-office).
